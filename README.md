# The Queen — Haute Dermatologie (v2)

React (Vite) storefront + admin · Node.js / Express API · SQLite. One Node app, ready for Hostinger.

See [PLAN.md](PLAN.md) for the full plan, brand identity and feature list.

## Run locally

```bash
npm install                 # server deps (root)
npm run build               # installs client deps + builds React into server/public
npm start                   # http://localhost:3000
```

Dev mode with hot reload (two terminals):

```bash
npm run dev:server          # API on :3000
npm run dev:client          # Vite on :5173 (proxies /api and /uploads)
```

- Storefront: `/` · Admin: `/admin`
- First start seeds the catalogue (3 products, same prices as the old site), the 58 wilayas with delivery prices, a demo coupon `QUEEN10`, and an admin account from `ADMIN_EMAIL` / `ADMIN_PASSWORD`. Products start with **stock 0** (set real stock in Admin → Stock). If `ADMIN_PASSWORD` is not set, a random one is generated and written to `FIRST-LOGIN.txt` inside the data folder.

## Order statuses & stock

`Nouvelle → Confirmée → En préparation → Expédiée → Livrée`, plus `Injoignable`, `Annulée`, `Retour`.
Stock is reserved when an order is placed, restored automatically on *Annulée* / *Retour*, and deducted again if the order is reopened. Every movement is logged (Admin → Stock).

## Deploy on Hostinger (Node.js app)

1. Run `npm run build` locally so `server/public` is up to date (Hostinger then needs no React build).
2. Upload the project **without** `node_modules`, `client/node_modules`, `server/data`, and with `.env` excluded (zip or Git).
3. hPanel → **Websites → Node.js** (or *Add website → Node.js app*):
   - Node version: **20.x** (or 22.x)
   - Entry file: `server/index.js` · Install: `npm install` · Start: `npm start`
4. Environment variables:
   - `JWT_SECRET` — long random string
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — used only to create the first admin
   - `DATA_DIR` and `UPLOAD_DIR` — optional. By default the database and uploaded images live in `~/the-queen-data/{db,uploads}`, **outside the deployed folder**, so redeploying a new version never wipes orders, stock or images. Never delete that folder; back it up.
5. Point `the-queen.shop` to the app and enable SSL.

`better-sqlite3` ships prebuilt Linux binaries; if the install compiles from source on the host, make sure the Node version matches the one selected above.
